# 验证记录

验证日期：2026-10-23。环境：Windows 11、Python 3.13.9、Flask 3.1.2、Werkzeug 3.1.3、SQLite 3.51.0、pytest 8.4.2。

## 自动化测试

全套结果：**334 passed in 157.76s**，零失败、零错误、零跳过。命令见 [README](../README.md)。

主要覆盖：

- 登录、CSRF 令牌轮换、角色与工单归属、列表筛选和分页、输入边界。
- 状态流转、处理结果与历史同事务；语句失败、提交失败后的回滚与恢复。
- 两个处理人竞争更新时只允许一个成功，失败方不覆盖结果。
- 请求编号、统一错误和日志敏感信息检查。
- 文档导入幂等、批次回滚、更新后引用失效、原文与行号核对。
- 模型开关、错误引用、资料变化、超时与 HTTP 中断、预算限制、本地密钥配置。

每个用例使用独立临时数据库与会话。pytest 中的模型网络均为模拟传输，不产生调用费用；参数化输入分别计数。

## HTTP 流程演示

`scripts/demo_workflow.py`：**42次本机 HTTP 请求、17组检查通过**。

覆盖创建、查询、权限隔离、状态更新、处理结果、状态历史、知识检索与来源核对，以及重建服务后的持久化。使用临时库与模拟账号，结束后关闭服务并清理本次数据；模型关闭。

## 检索与模型

`scripts/evaluate_knowledge.py` 使用6篇示例资料和18个开发问题：12个可答问题均首项命中预期文档，6个无答案问题均为空，12次来源核对通过。

`scripts/check_model.py --live` 单次真实连接通过；随后 `--live --suite` 的6个固定样例通过：

- SQLite 锁、CSRF 旧令牌和 Nginx 502 获得回答，引用预期文档，原文片段、行号与校验值一致。
- 火星传感器、HTTP 503、用 HTTP 502 问硬盘坏道均返回资料不足，不调用模型。

累计4次真实模型调用。按验证时的保守费率估算0.008274元；账本预占2元属于额度控制，实际费用以平台账单为准。报告保留人工语义审核标记。
