# 简历描述与演示

项目名称：**故障工单与知识检索系统｜个人项目**

技术栈：Python、Flask、SQLite、pytest、DeepSeek API。

[项目仓库](https://github.com/moonfellstargone-netizen/incident-ticket-backend)

## 后端方向

- 实现工单创建、分页查询、状态流转和处理结果记录，按角色及归属控制访问；通过条件更新和事务保证工单与历史记录一致。
- 实现会话登录、CSRF 校验、参数校验和统一错误返回，通过请求编号关联接口响应与后台日志。
- 实现故障文档导入与工单关联检索，调用 DeepSeek 生成带来源的辅助回答，支持文档更新、引用核对和无资料拒答。

## 测试开发方向

- 使用 pytest 覆盖业务流程、权限、输入边界和状态规则，采用独立数据库与会话隔离数据，334项测试通过。
- 模拟数据库写入与提交失败，验证工单和历史回滚、错误日志及故障恢复；保留缺陷复现与回归用例。
- 编写 HTTP 流程演示和知识检索检查脚本，验证重启持久化、资料来源及无答案处理，区分模拟响应与真实模型调用。

按投递岗位选择一组描述，两组对应同一个个人项目。工单和故障资料为模拟数据。

## 五分钟演示

1. 运行 `scripts/demo_workflow.py`，展示创建、查询、状态推进和处理结果。
2. 打开一条状态更新及对应测试，解释权限、条件更新和事务回滚。
3. 展示检索片段、原文来源与模型验证报告，再讲一个[排查案例](troubleshooting.md)。
