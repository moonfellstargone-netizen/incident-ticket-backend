## 投 Python 后端时

**故障工单后端与自动化验证｜个人项目，AI 辅助开发**

技术：Python、Flask、SQLite、pytest。

- 基于 Flask 和原生 sqlite3 实现工单创建、分页查询、状态筛选和解决流程；状态、处理结果、解决人及可查询的变更历史在同一事务中保存，竞争更新返回冲突。
- 实现会话登录、密码哈希和 CSRF 校验，区分提单人与处理人；列表和详情均限制数据可见范围，使用统一 JSON 错误及参数校验拒绝非法请求，通过请求编号关联响应与后台日志。
- 实现模拟 Markdown 资料导入、工单关联检索及来源核对，返回原文片段、行号和校验值；重复导入不新增，更新文档后旧分块引用失效，检索不足时明确返回资料不足。

验证证据：298项 pytest 通过，42次真实本机 HTTP 请求、17组检查通过；固定18题开发回归通过，结果不作为独立准确率。可选 DeepSeek 回答接口已实现引用、超时和预算限制，但真实模型尚未调用，不在简历中写“已完成可靠 RAG”。

展示时优先解释状态规则、数据库事务、权限和资料如何关联工单。测试数量包含参数化用例，不等于298种独立业务能力。

4. **2:30—3:30：展示验证证据。**打开 `tests/test_ticket_workflow.py`，选择非法状态零修改或数据库故障恢复用例，讲清准备数据、发请求、检查响应及数据库四步。完整测试方法与本次结果见[验证记录](verification.md)。
