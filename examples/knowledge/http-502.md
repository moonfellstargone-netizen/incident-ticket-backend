# Nginx HTTP 502：上游连接被拒绝

资料性质：个人项目自编模拟故障，仅用于检索和来源核对，未发生于真实生产环境。

## 现象与适用范围

模拟 Nginx 代理向应用发送请求时，客户端收到 HTTP 502，代理日志出现 `connect() failed (111: Connection refused) while connecting to upstream`。本例限定为上游应用端口没有监听，并不覆盖所有 502 原因。

## 核对步骤

先核对 Nginx upstream 配置的目标地址和端口，再在应用所在机器核对进程是否启动、端口是否监听。从代理机器检查到目标端口的连通性。不要仅凭 HTTP 502 就认定数据库损坏。

## 模拟处理与回归

本例发现演示应用没有启动；启动应用后重新检查目标端口，再分别直接访问应用与经过代理访问同一路径，记录 HTTP 状态和对应日志。两条路径都成功后才记录为本例恢复。配置修改应先复核再执行。

## 限制

本例没有覆盖上游证书错误、超时或响应格式错误；未记录任何真实域名、账号或密钥。
