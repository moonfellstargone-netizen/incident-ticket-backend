# INVALID_REQUEST 400：JSON 字段类型不符合接口约定

资料性质：个人项目自编模拟接口校验故障，仅供学习与回归验证。

## 现象与适用范围

模拟创建工单时把 title 写成数字，或者缺少 description 字段，服务返回 HTTP 400 和 INVALID_REQUEST。接口要求 JSON 对象恰好包含 title、description 两个字段，且两者都是有效 UTF-8 字符串。

## 核对步骤

核对 `Content-Type: application/json`，检查字段名称、类型、长度与多余字段。title 去除首尾空白后为 1 到 100 个字符，description 为 1 到 2000 个字符。不要发送 NUL、无效 Unicode 代理字符或空白正文。

## 模拟处理与回归

先保存可复现的错误输入，确认返回 400 且数据库没有新增，再仅把错误字段改为有效字符串并重试。成功响应应为 201，随后读取详情并核对保存内容。错误媒体类型应返回 415，而不是据此判定为数据库故障。

## 限制

本例仅对应本项目创建工单接口；其他接口使用各自的字段和长度约定。
