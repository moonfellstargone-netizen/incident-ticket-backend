# CSRF_FAILED 403：登录后仍使用旧令牌

资料性质：个人项目自编模拟故障，用于本项目 Cookie 会话与 CSRF 校验演示。

## 现象与适用范围

模拟客户端登录成功后创建工单，收到 HTTP 403 和错误码 CSRF_FAILED。客户端保留了登录前获取的 CSRF 令牌，未使用登录响应中的新令牌。

## 核对步骤

核对同一个 Cookie 会话是否贯穿获取令牌、登录和写请求；检查写请求的 `X-CSRF-Token` 头是否使用登录响应返回的令牌。日志只记录请求编号和错误，不复制 Cookie、密码或令牌。

## 模拟处理与回归

登录会更换会话和 CSRF 令牌，后续写操作应使用新令牌并保留对应 Cookie。用旧令牌再次创建应返回 403 且数据库无新增；改用新令牌后同一有效工单应创建成功。令牌属于具体会话，不能在不同客户端之间混用。

## 限制

本例没有覆盖跨域 Cookie 配置、浏览器代理扩展或单点登录服务，不应通过关闭 CSRF 校验绕过错误。
